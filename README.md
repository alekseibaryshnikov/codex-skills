# Codex skills

Reusable skills for designing and building software with Codex.

## Modern Web App Design

[design-web-apps](design-web-apps/SKILL.md) guides the creation and redesign of web apps with clear tasks, a distinctive visual identity, complete interactions, and responsive layouts.

The skill includes:

- The primary design workflow and separate usability and visual-craft reviews.
- Contemporary visual references and 2026 research, with 2027 directions identified as forecasts.
- Clarity, accessibility, performance, and implementation checklists.
- Agent metadata with implicit invocation enabled and an SVG icon.

The complete skill is contained in `design-web-apps/`. Keep its `references`, `agents`, and `assets` folders together with `SKILL.md` when installing it in a compatible skill environment. After installation, it can be invoked explicitly as `$design-web-apps` or selected automatically for matching tasks when the host supports implicit invocation.
